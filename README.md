# Plot

Plot is a small collection of Matplotlib helpers for creating publication-ready
line, scatter, bar, histogram, heatmap, radar, word-cloud, network and Sankey
plots, all through one class, `ALL_PLOT`.

Plot code heavily borrowed from https://python-graph-gallery.com/

## Quick start

```python
from ALL_PLOTS import ALL_PLOT
from colors_set import DISTINCT_3_6

plotter = ALL_PLOT(
    figsize=(6, 6),
    colors=DISTINCT_3_6,
    artificial_darkening=0.8,
)

plotter.plot(
    plt_type="line",
    name="Pictures/Lines/my_line_plot",
    Lines=[
        [[0, 1, 2, 3], [10, 45, 35, 75]],
        [[0, 1, 2, 3], [20, 30, 55, 60]],
    ],
)
```

## Installation

`seaborn` is imported by `colors_set.py`, `wordcloud` is used by word clouds, and
`networkx` and `netgraph` by network bubble plots.

```bash
python -m pip install matplotlib torch numpy pandas
python -m pip install seaborn wordcloud networkx netgraph
```

Run the example scripts from the repository root. Each writes its images into
`Pictures/`:

```bash
python test_line.py
python test_scatter.py
python test_hist.py
python test_heatmap.py
python test_misc.py
```
